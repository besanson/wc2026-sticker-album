Two things worth flagging to a coach rather than burying in a log line:

- **Home advantage is unusually small.** 0.124 goals, against a literature

  this). We checked it isn't a bug: raw per-season goal differential
  (home minus away) in `results.csv` has fallen from +0.26 in 2023-24 to

  rarer than an independent-Poisson model would predict (58 actual vs.
  86.3 expected) while 1-1 draws are notably more common (144 vs. 124.5) —
  a genuine, if mixed, pattern in this specific 1,126-match sample, not an
  implementation error.

## Tier 2 — player-level lineup model

### Why Tier 2 can't rate this fixture

Tier 2 needs two things for a specific match: a starting-lineup file, and
player-level ratings for the players in it. Neither exists for the actual
Udinese vs Cagliari fixture:

1. No lineup file was supplied for it (`data/lineups/` is empty).
2. Even with one, there is no 2026-27 Serie A event data to rate either
   squad's current players from — FBref's advanced data feed has been
   unavailable since Opta pulled it in January 2026 (CLAUDE.md section 1),
   and no other open, current event-data source exists. StatsBomb's open
   data does not cover any current competition.

Running `matchsim predict --tier 2` on the real fixture (no `--lineups`)
prints this explanation and exits rather than guessing. This is a genuine
data-availability gap, not a missing feature — Tier 2's own design (spec
section 2) frames StatsBomb/Wyscout as "demo and validation" sources for
exactly this reason.

### Matchup-style interaction term (spec 4.4): tried, dropped, and why

A directness-times-press-intensity interaction term was added to the
calibrated link and evaluated on held-out game splits, exactly as the spec
asks. It looked favourable by RPS alone (mean delta -0.0099 across 6
splits, i.e. an improvement 5 times out of 6) — but including it flips the
link's core `beta_strength` coefficient from +1.48 to -23.17, because
`attack_diff` and the interaction term correlate (~0.3) at very different
scales. A model that would tell a coach "your team's better attack rating
predicts *fewer* goals" fails the spec's own bar ("Explanation is a
feature, not a log line") regardless of what a single metric says, so the
term is dropped from the shipped model. See `reports/eval.md` for the full
numbers.

## For the head coach

Udinese go into this one as favourites at home, but not strongly: Dixon-Coles
gives them a 46.5% chance of a win, 33.2% for a Cagliari win, and a 20.3%
draw. The most likely single outcome is a narrow 1-0, with combined expected
goals of about 2.5 across the match — an ordinary, roughly-average Serie A
scoring rate, not a shootout and not a stalemate either. The model's
uncertainty band is wide (Udinese's win probability could reasonably be
anywhere from 37% to 56%), which is normal for a single Serie A fixture and
shouldn't be read as the model being unsure of itself in a bad way — it's an
honest reflection of how much a 90-minute football match can vary.

Two caveats worth knowing before acting on this: home advantage has been
shrinking across the seasons in our data (it's now worth about 0.12 goals,
well below the historical Serie A norm of 0.25-0.40), so don't lean on
"they're at home" as a strong factor this season. And we cannot yet give
you a player-level breakdown for this specific match — no current-season
event data exists to rate this squad's individual players from, so
anything at the player level would be a guess dressed up as a number. What
you're seeing here is a team-level read from real results, not a lineup
read; treat it as the seasoned-observer's gut estimate, not a scout report.

## Tier 3 — possession-sequence stub (experimental, spec section 5)

Built after this report, since Tiers 1 and 2 pass their tests. A small GRU
(456-token vocabulary: home/away flag x SPADL action type x result x a
coarse 3x3 pitch zone) trained for 8 epochs on 120 of the 150 demo games,
then used to generate 2,000 simulated matches action-by-action (capped at
2,200 tokens), aggregated to a scoreline distribution.

**This stub has no team-identity conditioning** — it generates "an average
match," not a specific fixture, so it's evaluated the way a baseline is:
one shared distribution scored against all 30 held-out demo games.

| Model | RPS (30-game demo holdout) |
| --- | --- |
| Tier 3 (unconditional GRU) | 0.2126 |
| Naive baseline (same demo data) | 0.2103 |
| Dixon-Coles fit on the same 120 demo games | 0.2415 |
| *(reference)* Tier 1 on real, 344-game 2025-26 holdout | 0.2169 |

By the spec's literal rule ("include only if RPS is within 0.01 of Tier
1"), this passes against the real Tier 1 number (|0.2126-0.2169|=0.0043).
**But that's not the honest headline**: the naive baseline is *also* within
0.01 of Tier 1 (0.0066) using zero modelling at all, and Dixon-Coles itself
underperforms both when starved down to 120 games (too few matches per
team to estimate attack/defence reliably at this demo scale). Tier 3's
"pass" mostly shows it learned realistic baseline outcome rates, not that
sequence generation is capturing real match-specific signal here — RPS
values for football's three-way outcome are naturally clustered close
together, so "close to Tier 1" is an easier bar to clear than it sounds.
A team-conditioned version would be the real test; that's future work
beyond this stub's scope.

Not attempted: team/player-conditioned generation (would hit the same
no-current-player-data wall as Tier 2).
